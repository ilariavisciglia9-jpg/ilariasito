# Sorgenti del sito (non pubblicati)

GitHub Pages ignora le cartelle che iniziano con `_`, quindi questi file non finiscono online.

- `style.css` — tutto lo stile (tema computer / videogame)
- `app.js` — animazioni, PC 3D con Three.js, assistente AI
- `build.py` — genera tutte le pagine `.html` con CSS e JS incorporati

Per rigenerare le pagine dopo una modifica qui: `python3 _src/build.py`
(Attenzione: sovrascrive le pagine .html della cartella principale.)
